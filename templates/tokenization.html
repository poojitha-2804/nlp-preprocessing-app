All 11 Tokenization Types Explained

Type 1
Sentence Tokenization

Splits raw body text into full sentence strings based on sentence boundary delimiters like `.`, `!`, and `?`.

Input: "NLP is great. We love AI!"
Output: ["NLP is great.", "We love AI!"]
Type 2
Word Tokenization

Separates text into individual words, numbers, and isolated punctuation marks.

Input: "Natural Language Processing is amazing."
Output: ["Natural", "Language", "Processing", "is", "amazing", "."]
Type 3
Character Tokenization

Decomposes text into every single individual character, including letters, digits, whitespace, and symbols.

Input: "AI"
Output: ["A", "I"]
Type 4
Subword Tokenization

Decomposes complex or rare words into smaller prefix, stem, or suffix subword units (e.g. `##ing`). Essential for modern Transformer models (BERT/GPT).

Input: "unhappiness"
Output: ["un", "##happy", "##ness"]
Type 5
Whitespace Tokenization

Splits strictly on space, tab, or newline characters. Punctuation remains attached to adjacent words.

Input: "Hello, world!"
Output: ["Hello,", "world!"]
Type 6
Punctuation Tokenization

Explicitly isolates punctuation boundaries from surrounding word tokens.

Input: "state-of-the-art"
Output: ["state", "-", "of", "-", "the", "-", "art"]
Type 7
Regular Expression Tokenization

Uses regular expression patterns (e.g., `\w+`) to match and filter specific token patterns like alphanumeric words.

Pattern: `\b\w+\b`
Output: ["Natural", "Language", "Processing"]
Type 8
N-gram Tokenization

Groups contiguous sequences of N words together (Bigrams: N=2, Trigrams: N=3) to preserve local word order context.

Input: "machine learning model"
Bigrams: ["machine learning", "learning model"]
Type 9
Byte Pair Encoding (BPE)

Iteratively replaces the most frequent pairs of characters in a corpus with new merged subwords (used in GPT tokenizers).

Tokens: ["low</w>", "low", "er</w>", "est</w>"]
Type 10
WordPiece Tokenization

Subword algorithm used by BERT that maximizes likelihood score when selecting subword vocabulary tokens (using `##` prefix).

Input: "tokenization"
Output: ["token", "##ization"]
Type 11
Unigram Tokenization

Starts with a huge subword vocabulary and iteratively prunes subwords with lowest loss impact (used in SentencePiece).

Input: "unigram"
Output: ["uni", "gram"]
