# SVCET NLP Lab - Part-Of-Speech (POS) Tagging
import nltk
from nltk.tokenize import word_tokenize
from nltk import pos_tag

text = "this is a book"
tokens = word_tokenize(text)
tagged = pos_tag(tokens)

print("POS Tagged Tokens:")
for token, tag in tagged:
    print(f"Token: {token:10} | Tag: {tag}")

POS Tagset Quick Reference Guide

Comprehensive dictionary of standard Part-Of-Speech tags used in Natural Language Processing.

Determiner (DT)
Determiner / Article

Words that specify or quantify nouns: this, a, the, that, these.

Verb (VB / VBZ)
Verb / Action

Words expressing action, state, or occurrence: is, are, runs, reads, builds.

Noun (NN / NNS)
Noun / Subject

Names of people, places, things, or concepts: book, computer, student, city.

Adjective (JJ)
Adjective / Modifier

Words modifying or describing nouns: good, green, fast, intelligent.
