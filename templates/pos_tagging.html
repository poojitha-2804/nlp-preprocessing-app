POS Tagging Frameworks & Tagsets

Tagset 1
Penn Treebank Tagset (36 Tags)

The standard fine-grained POS annotation scheme used in NLP. Distinguishes singular/plural nouns (NN/NNS), proper nouns (NNP), verb tenses (VB, VBD, VBG, VBZ), determiners (DT), etc.

Example: "The/DT children/NNS were/VBD running/VBG fast/RB ./."
Tagset 2
Universal POS Tagset (17 Categories)

A cross-linguistic coarse-grained tagset standardized by Universal Dependencies. Maps all fine-grained tags into 17 primary universal grammatical categories (NOUN, VERB, ADJ, ADV, PRON, ADP, etc.).

Example: "The/DET children/NOUN were/AUX running/VERB fast/ADV ./PUNCT"
Engine 1
NLTK Perceptron Tagger

Uses a sequence-labeling Averaged Perceptron model trained on the Wall Street Journal corpus. Highly accurate and fast for English text.

Engine 2
SpaCy Contextual Tagger

Uses deep neural convolutional network embeddings and transition-based dependency parsing for context-aware part-of-speech tagging.

Engine 3
Rule-Based / Lexicon Tagger

Uses explicit closed-class dictionaries (determiners, prepositions, pronouns, conjunctions) combined with suffix heuristics for lightweight execution.
